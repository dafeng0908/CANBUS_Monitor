## Generated code

- Core/, Drivers/ and Middlewares/ may be regenerated by STM32CubeMX.
- Do not place application logic inside generated callback bodies.
- USER CODE blocks may contain only forwarding calls.

## Handwritten code

- App/ and BSP/ are manually maintained.
- App/ must not include STM32 HAL headers.
- BSP/ is the only layer allowed to call HAL FDCAN APIs.
- Protocol code must be host-testable without STM32 hardware.
