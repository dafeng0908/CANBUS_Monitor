# Project Definition

## Product Vision

Build an AI-assisted CAN FD development platform based on NUCLEO-C542RC.

## In Scope

- STM32 HAL
- FreeRTOS
- FDCAN
- Python Qt6 GUI
- Cppcheck
- Ceedling
- Automated reports

## Out of Scope for MVP

- CANopen
- J1939
- DBC decoding
- OTA update
- Multi-device support

## Hardware Baseline

- NUCLEO-C542RC
- Onboard CAN FD transceiver
- USB or UART host communication

## Software Baseline

- STM32CubeC5
- STM32 HAL
- FreeRTOS
- Python 3
- Qt6
- Cppcheck
- Ceedling
